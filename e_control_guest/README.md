# e-Control Guest

Condivide schede Home Assistant selezionate con ospiti tramite link temporanei,
senza esporre account, token Supervisor o accesso al resto dell'impianto.

Dopo l'installazione, apri l'interfaccia Web dell'add-on, crea un profilo,
seleziona una scheda e scegli per ogni entità se consentire lettura e comandi.
Consulta `DOCS.md` prima di esporre la porta Guest.
